Agents that dream.

The PokéCenter is north south of the gym.

An agent kept the first version in its notes. In two sessions it walked north of the gym and found nothing. In a third it found the PokéCenter to the south. The note still said north.

agentdream reads an agent's notes and its recent session logs while the agent is idle, and stages a corrected copy: duplicates merged, stale values replaced, wrong notes fixed with the lines that prove it. You review the changes before anything is written.

pip install agentdream

Runs on your machine, with no dependencies and no model required. MIT licensed.

One dream, charted

A sleep lab charts a night as a line that steps between stages. This is the same chart for a dream: each step shows where that phase is working. The line touches your files once, to read them, and does not come back until you accept.

  1. loadReads the memory store (markdown, JSON, SQLite) and the transcripts, keeping a file and line reference on every message.
  2. redactScrubs API keys, tokens, passwords and card numbers before anything is analysed or sent to a model.
  3. limitsTrims oversized inputs with a notice, or stops if you asked it to fail instead.
  4. consolidateMerges duplicate notes, keeps the newest of two dated values, resolves reversed preferences.
  5. verifyCompares each note with what the transcripts show and corrects the ones the evidence contradicts.
  6. insightsRecords what recurs across sessions: repeated preferences, repeated mistakes, settled workflows.
  7. writeWrites the new store, a report and a diff into the staging folder.

      What these numbers do not show:

      From Claude Code

      Three ways in. Each one starts as a dry run.

      Ask for a dream

      Install the skill, then type /dream. Claude runs a dry-run dream, walks you through the report and applies only what you approve.

      agentdream install-claude-skill

      Let it run after sessions

      A background dream after every third session. With --safe, merges and stale-value replacements are applied with a backup. Corrections wait for you.

      agentdream install-claude-hook --every 3 --safe

      Give Claude the tools

      An MCP server with dream, show_report and accept. The same server works in Cursor.

      claude mcp add agentdream -- agentdream serve-mcp

      Or by hand, on any agent's memory

      agentdream dream --memory ./memory --sessions "./logs/*.jsonl"   # dry run
agentdream show <job-id>                                          # what changed and why
agentdream accept <job-id> --only correct-2ec6281c                # apply some of it
agentdream restore <job-id>                                       # undo an accept

      The default engine is rule-based and offline. --backend switches to Anthropic, any OpenAI-compatible server, Ollama, LM Studio, vLLM or your Claude Code login.

      Struck from the design

      • Changes your memory while you are awayA dream never writes to the store it read. Nothing is applied until you accept, or until you opt in to automatic updates.
      • Leaves no way backEvery accept backs up the store first and refuses to run if the store changed since the dream. One command restores it.
      • Sends your secrets to a modelKeys, tokens and passwords are redacted before analysis, again over every prompt, and again over every quote in the report.
      • Takes a model's word for itA proposal that names a note or a transcript line that does not exist is dropped. A correction without verifiable evidence is downgraded to a flag.
